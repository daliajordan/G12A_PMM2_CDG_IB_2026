## Description
*La PMM2-CDG és una malaltia genètica on falla l'enzim fosfomanomutasa 2. Aquest enzim és necessari per fabricar glicans (cadenes de sucres que s'enganxen a les proteïnes). Sense ell, moltes proteïnes no funcionen bé, i això afecta diversos òrgans alhora, sobretot el sistema nerviós.*
